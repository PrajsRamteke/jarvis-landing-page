        // DEPLOYMENT PROTOCOL
        
INSTALL IN 3 STEPS

        
No accounts. No clicking around. Brew, curl, summon.

      


      

        

          
01

          

            
 PREP THE RUNTIME

            
Grab Python 3.11 via Homebrew — the only prerequisite.

            

              
$ brew install python@3.11

              
            

          

          

        


        

          
02

          

            
 RUN THE INSTALLER

            
One command pulls the source, builds the environment, and registers the jarvis CLI.

            

              
$ curl -fsSL https://raw.githubusercontent.com/PrajsRamteke/harness-agent/main/scripts/install | bash

              
            

          

          

        


        

          
03

          

            
 SUMMON

            
That's it. Launch the TUI, authenticate once — API key or OAuth — and start commanding.

            

              
$ jarvis

              
            

          

          

        

      


      

        
        optional: export ANTHROPIC_API_KEY=sk-... to skip the auth prompt entirely
