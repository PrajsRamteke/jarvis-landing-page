Overview

Jarvis is a terminal-native AI coding agent — the Harness Agent that lives in your terminal. Talk to it, and it reads/writes files, runs shell commands, searches code, manages git, controls macOS apps, OCRs images, browses the web, and gets work done right where your code lives.

Install

One-command install (recommended)

curl -fsSL https://raw.githubusercontent.com/PrajsRamteke/harness-agent/main/scripts/install | bash
source ~/.zshrc

After install, open a new terminal, go to any project, and run jarvis.

Troubleshooting: If jarvis: command not found, add ~/.local/bin to your PATH: export PATH="$HOME/.local/bin:$PATH"

Development setup

git clone https://github.com/PrajsRamteke/harness-agent.git
cd harness-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
jarvis --help

Run the agent

jarvis                     # TUI mode (default)
python agent.py            # same as jarvis
python agent.py --legacy   # Rich REPL mode

TUI Interface

The interactive TUI is built with Textual. Run jarvis from your project folder to start it.

  • Conversation area — scrollable chat with markdown rendering, syntax-highlighted code
  • Prompt input — multi-line text area. Type and press Enter to send
  • Status bar — project path, provider, model, agent, token count
  • Thinking panel — live view of the model's reasoning process
  • Tool viewer — press F3 to scroll through recent tool outputs

Reference files with @, run bash with !, drag-and-drop images for OCR.

Web Remote

Enable the mobile-friendly browser UI with jarvis --web.

jarvis --web        # default port 8765
jarvis --web 9090   # custom port

A QR code is shown in the terminal. Scan it with your phone or open the URL in any browser on the same network.

Context Tools

The connected context pack replaces 5-20 separate file reads with a single call.

resolve_context

Give it a task description and get all related files — targets, imports, importers, tests, types, configs.

resolve_context(task="Fix login bug in JWT token refresh")
# Returns: jwt.py, auth.py, middleware.py, test_auth.py,
#          types.py, config.py — all in one shot

read_bundle

Batch-read 2-20 paths with parallel I/O and budget-aware output capping.

read_bundle(["src/auth.py", "src/middleware.py", "src/types.py"])

Tool Repair

14-stage auto-repair pipeline validates and fixes model-generated tool inputs before execution.

  1. Parse stringified args
  2. Unwrap envelopes
  3. Fix field aliases
  4. Strip null values
  5. Strip extra fields
  6. Parse stringified arrays
  7. Parse stringified objects
  8. Fix wrong containers
  9. Clean paths
  10. Fix string numbers
  11. Fix boolean strings
  12. Coerce to string
  13. Fix markdown paths
  14. Repair nested arrays

Each fixer is idempotent — correct inputs pass through unchanged. The UI shows a ⚒ indicator when repairs were applied.

Plan Mode

Restricts Jarvis to read-only operations. Analyze, suggest, explain — but no writes, no shell.

/plan on    # Enter plan mode
/plan off   # Exit plan mode

Available: read_file, resolve_context, search_code, glob_files, git_*, web tools, ask_user_question.

Pinned Context — Always-On Prompt

Text injected with every single prompt. Stored in ~/.config/harness-agent/pinned.txt.

Unlike a one-shot instruction, pinned context is injected before every message.
CommandAction

/pin clearClear
/pin toggleEnable/disable

Use cases: code style rules, security policies, behavior instructions, formatting preferences.

FAQ

▸ How do I update Jarvis?

Run /upgrade in the TUI. It pulls the latest version from GitHub.

▸ Can I use Jarvis offline?

Core file/git/shell tools work offline. The LLM needs an internet connection for API calls.

▸ Does it work on Linux or Windows?

Core agent works on any platform. macOS control tools are macOS-only.

▸ How do I switch providers?

Type /provider in the TUI or set HARNESS_PROVIDER env var.

▸ How is my data handled?

All data is local — SQLite sessions, JSON memory. No telemetry sent anywhere.

Troubleshooting

Jarvis won't start

brew install python@3.11

"command not found: jarvis"

export PATH="$HOME/.local/bin:$PATH"

Authentication issues

  • Check ANTHROPIC_API_KEY: echo $ANTHROPIC_API_KEY
  • Run /login to re-authenticate

macOS accessibility denied

  1. System Settings → Privacy → Accessibility
  2. Add your terminal app
  3. Restart terminal
